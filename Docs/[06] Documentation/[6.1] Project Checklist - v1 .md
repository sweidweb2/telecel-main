### The most important thing

There are **three layers you should never mix**:

```text
┌───────────────────────────────┐
│       BUSINESS                │
│ What should the system do?   │
└───────────────┬───────────────┘
                ↓
┌───────────────────────────────┐
│       TECHNICAL               │
│ How should we implement it?  │
└───────────────┬───────────────┘
                ↓
┌───────────────────────────────┐
│       PRESENTATION            │
│ How should the user see it?  │
└───────────────────────────────┘
```

For example:

**Business:**
"A project manager can approve a worker's expense."

**Technical:**
`POST /expenses/:id/approve` → authorization → transaction → update expense → audit log → notification.

**Presentation:**
Expense table → Approve button → confirmation modal → loading → success toast.

If you prepare those three levels **for every major feature**, your AI agent will have a much clearer specification and you'll avoid the common problem of it building beautiful pages while the actual business logic is incomplete.
