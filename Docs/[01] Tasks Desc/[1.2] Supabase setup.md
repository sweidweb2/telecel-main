
🛢 Supabase Project Setup & Connection

**Supabase Setup Checklist**

- [ ] Create Supabase project in the region closest to your primary user base (to minimize latency)
- [ ] Retrieve API credentials from Project Settings → API:
    - [ ] Project URL
    - [ ] anon (public) key
    - [ ] service_role (secret) key
- [ ] Create `.env.local` with the following variables:
    - [ ] `NEXT_PUBLIC_SUPABASE_URL`
    - [ ] `NEXT_PUBLIC_SUPABASE_ANON_KEY`
    - [ ] `SUPABASE_SERVICE_ROLE_KEY` (server-only, *no* NEXT_PUBLIC_ prefix)
- [ ] Add/commit `.env.example` with placeholder values only (no real secrets)
- [ ] Confirm `.env.local` is included in `.gitignore` (should never be committed)
- [ ] Add the same environment variables to your deployment platform (e.g., Vercel) under the correct environment scope
- [ ] Test connection:
    - [ ] Client-side: Supabase call succeeds
    - [ ] Server-side: Supabase call succeeds
    - [ ] Admin (service role): connection works from a server-only context
- [ ] Notify sweid once everything is verified and working end-to-end
