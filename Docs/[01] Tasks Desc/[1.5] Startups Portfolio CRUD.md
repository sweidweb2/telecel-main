## Trello Card: Admin + Public Portfolio — Startups CRUD

**Title:**
`Build startups CRUD on /dashboard/portfolio + public /{locale}/portfolio`

**Description:**
Add a `startups` CMS entity so admins can create, edit, feature, and delete portfolio companies from the existing `app/(dashboard)/dashboard/portfolio/` route (`ROUTES.portfolio` / “Manage portfolio” in the sidebar), and so the public marketing portfolio lists and detail pages under `app/(marketing)/{en|fr}/portfolio/` render real data. Depends on Auth + `profiles` / `is_admin()` and SEO helpers (`buildMarketingMetadata`, alternates). Out of scope: users CRUD, registrations, insights/blog CMS, and inventing a parallel `app/(admin)/startups/` tree.

**Blocking decisions (resolve before starting):**
1. **Status enum vs draft** — Checklist mentions public vs draft, but the proposed statuses are only `active` / `alumni` / `graduated`. Decide the final enum (e.g. include `draft`) and which values are publicly selectable.
2. **Description storage + editor** — Choose `jsonb` (structured editor doc) vs HTML/`text`, and which rich-text + sanitizer libraries to add (none are in `Docs/libraries.md` yet). Do not invent an unapproved stack mid-task.
3. **Gallery model** — `text[]` / `jsonb` URL array on `startups` vs separate `startup_gallery` table (ordering, captions, per-image RLS).
4. **i18n content** — Single-language startup rows vs locale-specific fields / translation table for en+fr public pages (routes are bilingual today; schema is not).
